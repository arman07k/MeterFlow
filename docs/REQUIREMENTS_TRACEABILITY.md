# MeterFlow Requirements Traceability Matrix (`docs/REQUIREMENTS_TRACEABILITY.md`)

## 1. Purpose & Status Definitions

This document provides individual, bidirectional traceability across **Functional Requirements (`FR1`–`FR10`)**, **Quality Attribute Requirements (`QA1`–`QA5`)**, and **Common Engineering Requirements (`C1`–`C12`)** (`C4`).

### Canonical Status Definitions

- **`Foundation Completed`**: Documentation/governance deliverable exists in the repository and passed automated consistency verification.
- **`Documented — Not Implemented`**: Architecture, schema, contracts, and acceptance tests are fully specified, while zero application code or migrations exist yet.
- **`In Progress`** / **`Verified`**: Reserved for future implementation tasks once source code and passing tests exist.
